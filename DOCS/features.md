# Funcionalidades de la aplicación

ParKol es una aplicación para la gestión de un parqueadero público con una capacidad de 50 cupos. Su propósito es facilitar el control de los vehículos que ingresan y salen, conocer la disponibilidad de espacios, gestionar reservas y llevar un registro de los pagos realizados.

## Funcionalidades de usuario

ParKol permitirá al usuario realizar de manera sencilla las principales acciones relacionadas con el uso del parqueadero. El usuario podrá:

1. **Consultar los cupos disponibles:** Podrá conocer cuántos espacios están disponibles en el parqueadero y cuáles se encuentran ocupados o reservados.

2. **Registrar la entrada de un vehículo:** Al ingresar al parqueadero se registrará la entrada del vehículo junto con la información necesaria para identificarlo.

3. **Registrar la placa:** Se podrá ingresar la placa del vehículo para llevar un control de su permanencia dentro del parqueadero.

4. **Seleccionar el tipo de vehículo:** Se podrá indicar si el vehículo es un carro 🚗 o una moto 🏍️, ya que las tarifas pueden variar dependiendo del tipo.

5. **Asignar un cupo:** Una vez registrado el vehículo, el sistema permitirá asignarle uno de los espacios disponibles.

6. **Reservar un cupo:** El usuario podrá reservar un espacio disponible para utilizarlo posteriormente.

7. **Consultar una reserva:** Podrá consultar la información de su reserva, incluyendo el cupo asignado y los datos correspondientes.

8. **Registrar la salida del vehículo:** Cuando el vehículo vaya a salir, se registrará la hora de salida utilizando la información guardada al momento de su ingreso.

9. **Calcular el tiempo de permanencia:** El sistema calculará automáticamente el tiempo que el vehículo permaneció dentro del parqueadero.

10. **Calcular el valor a pagar:** El valor se calculará automáticamente teniendo en cuenta el tiempo de permanencia y el tipo de vehículo.

11. **Registrar el pago:** Una vez calculado el valor correspondiente, se podrá registrar el pago realizado.

12. **Liberar el cupo:** Después de registrar la salida, el espacio utilizado volverá a aparecer como disponible.

## Funcionalidades de administrador

ParKol contará con un panel de administración que permitirá llevar un mejor control de las operaciones del parqueadero. El administrador podrá:

1. **Consultar el estado del parqueadero:** Podrá visualizar el estado de los 50 cupos, diferenciando los espacios disponibles, ocupados y reservados.

2. **Gestionar los vehículos:** Podrá consultar la información de los vehículos registrados y realizar las gestiones necesarias sobre ellos.

3. **Gestionar entradas y salidas:** Podrá registrar y consultar los movimientos de los vehículos dentro del parqueadero.

4. **Gestionar reservas:** Podrá consultar las reservas realizadas y, cuando sea necesario, modificarlas o cancelarlas.

5. **Gestionar las tarifas:** Podrá establecer o modificar las tarifas utilizadas para calcular el valor del servicio.

6. **Gestionar los pagos:** Podrá registrar los pagos realizados y consultar la información de los cobros.

7. **Consultar el historial de vehículos:** Podrá revisar los registros de vehículos que hayan utilizado el parqueadero anteriormente.

8. **Consultar información general:** Podrá visualizar datos como la cantidad de cupos ocupados, disponibles y reservados.

9. **Consultar los ingresos:** Podrá revisar los ingresos generados a partir de los pagos registrados en el sistema.
